# 后续开发计划

当前笔试 MVP 的核心闭环已经完成。若继续投入，按下列顺序扩展。

## P0：可靠性

- Provider 超时后自动切换到备用 Go 模型；
- 针对模型半截文件实现一次自动补全请求；
- 限制并清理危险外部网络请求；
- 为项目和版本增加删除、重命名。

## P1：生成能力

- 接入 esbuild-wasm，支持 React / TypeScript 多文件项目；
- 建立经过验证的组件和依赖白名单；
- 将运行错误、DOM 截图和当前文件一起回灌 Ray；
- 增加选中页面元素后自然语言修改。

## P1：产品化

- GitHub / 邮箱登录和项目所有权；
- 公开、私有、仅链接三种分享权限；
- 版本 diff 和修改原因溯源；
- 项目搜索、归档和模板市场。

## P2：全栈应用

- 使用隔离容器执行服务端代码；
- 每个生成应用独立数据库和密钥空间；
- 依赖安装缓存、冷启动优化、资源配额；
- 自动部署生成应用到独立域名。
