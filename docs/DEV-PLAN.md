# 后续开发计划

当前笔试 MVP 的核心闭环已经完成。若继续投入，按下列顺序扩展。

## P0：可靠性

- [x] 匿名工作区所有权与私有 API 隔离；
- [x] 同项目原子生成租约、过期回收和数据库唯一索引；
- [x] 客户端取消向上游模型请求传播；
- [x] 固定版本发布与已有公开项目迁移；
- [x] Vitest、Playwright 和 GitHub Actions 回归链；
- [ ] Provider 超时后自动切换到备用 Go 模型；
- [x] 针对模型半截文件实现一次自动补全请求；
- [x] 限制危险动态代码和外部脚本/样式；
- [ ] 为项目和版本增加删除、重命名。

## P1：生成能力

- [x] 持久化 generation run、Agent 有序事件、耗时、模型用量、调用次数、修复次数和失败原因；
- [x] 在工作台提供可展开的执行审计摘要；
- 接入 esbuild-wasm，支持 React / TypeScript 多文件项目；
- 建立经过验证的组件和依赖白名单；
- 将运行错误、DOM 截图和当前文件一起回灌 Ray；
- 增加选中页面元素后自然语言修改。

## P1：产品化

- 把匿名 owner ID 平滑升级到 GitHub / 邮箱账号；
- 公开、私有、仅链接三种分享权限；
- 版本 diff 和修改原因溯源；
- 项目搜索、归档和模板市场。

## P2：全栈应用

- 使用隔离容器执行服务端代码；
- 每个生成应用独立数据库和密钥空间；
- 依赖安装缓存、冷启动优化、资源配额；
- 自动部署生成应用到独立域名。
